# SVG and chart recipes

- **SVG** — exact layouts: memory, disk pages, packet headers, a network topology where placement matters. Write to `attachments/<topic>-<what>.svg`, give it a solid white background rect (readable in dark mode), `font-family="sans-serif"`, legible sizes. **Render and look before embedding**: convert it to PNG in the scratchpad (e.g. `qlmanage -t -s 1000 -o <scratchpad> attachments/<file>.svg` on macOS, `rsvg-convert` elsewhere), then Read the PNG. Compare every label, arrow and value with the sentence it illustrates, and fix and re-render before embedding.
- **Python chart** (matplotlib) — concrete numbers: latency vs load, cost curves, compression ratios, loss curves. Script in `attachments/_src/<name>.py`, run with `uv run --with matplotlib python attachments/_src/<name>.py`, saving `attachments/<name>.png` (white background, dpi 150). Read the PNG to check it before embedding. Use real or clearly labeled illustrative numbers — never invent data presented as real.
